# Java Billing System 🧾

A simple **console-based billing system built using Java**.

This project is being developed as part of my Java learning journey. I will continue improving and adding new features as I learn more Java concepts.

## 🚀 Current Features

* Customer name input
* Customer phone number input
* Predefined products with prices
* Item selection using item numbers
* Multiple items can be added
* Automatic bill calculation
* Basic bill receipt generation
* Console-based interface

## 🛠️ Concepts Used

* Java
* Variables
* User Input
* Scanner
* Conditional Statements
* Loops
* do-while Loop
* Basic Logic Building

## 📌 Current Version

**Version 1.0 — Basic Billing System**

The current version allows customers to select multiple products and calculates the total bill automatically.
